# Country Letters — لعبة أونلاين

سيرفر Node.js (WebSocket) + صفحة اللعبة. السيرفر هو اللي بيتحكم في كل حاجة (الحروف، الأرباع، التايمر 10 ثواني)، فمفيش غش من جهة اللاعبين.

## تشغيل على جهازك
```
npm install
npm start
```
افتح http://localhost:3000 (ولو صحابك على نفس الشبكة: http://IP-جهازك:3000).

## رفعها على الإنترنت (مثال: Render)
1. ارفع مجلد المشروع على GitHub (repo جديد).
2. على render.com: New ← Web Service ← اختار الـ repo.
3. Build Command: `npm install` — Start Command: `npm start`.
4. اضغط Deploy، وبعد دقيقة هتاخد رابط عام (https://...onrender.com) ابعته لصحابك.

ينفع كمان Railway أو Fly.io أو أي VPS فيه Node 18+. السيرفر بيقرا المنفذ من متغير `PORT` تلقائيًا، وبيدعم WebSocket من غير إعداد إضافي.

## ملاحظات
- الغرف محفوظة في ذاكرة السيرفر؛ لو السيرفر عمل restart الغرف بتتمسح.
- الخطة المجانية في Render بتنام بعد فترة خمول، فأول فتح ممكن ياخد نص دقيقة.
- لتعديل قائمة الدول: ملف `countries.js`.
- `/health` بيرجّع ok لفحص الصحة.
